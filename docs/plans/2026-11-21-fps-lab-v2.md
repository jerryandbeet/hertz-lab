# FPS & Smoothness Lab v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create an interactive, light-themed multimedia laboratory web application in Russian demonstrating display refresh rates, frame rates, and visual smoothness across 7 interactive stations with Three.js 3D graphics, Web Audio API, real-time telemetry, and hardware refresh rate detection.

**Architecture:** A single-page application built with Vite + React + TypeScript + Tailwind CSS. Component-based architecture split into: global telemetry engine (requestAnimationFrame monitor with 1% low and Hz detector), procedural Web Audio sound synthesizer, top floating Dynamic Island HUD, and 7 dedicated interactive station modules with high-fidelity canvas / Three.js renderers.

**Tech Stack:** React 19 / 18, Vite, TypeScript, Tailwind CSS, Lucide React, Three.js, Web Audio API, Playwright for E2E verification.

**Spec:** Designed based on neo-laboratory and Apple Pro Hardware guidelines, light clean glassmorphism (`backdrop-blur`, subtle borders, soft elevation shadows), Russian-language educational explanations, interactive sliders, and real-time interactive simulations.

## Global Constraints
- Target directory: `C:\google\fps-lab-v2` (do not touch `C:\google\fps-site`).
- Theme: Clean, light, high-tech laboratory aesthetics (no dark pitch-black background).
- Language: Russian for all titles, telemetry labels, interactive controls, and educational tooltips.
- Performance: 60+ FPS base UI, isolated canvas loops, interruptible spring-like interactions.
- Audio: Web Audio API with default muted state and an instant toggle in the Dynamic Island HUD.
- No subagents or swarm: execute tasks inline with verification.

## Review Focus
- Station switching: Instantaneous, zero memory leak from Three.js scenes or rAF loops.
- Audio synthesis: Browser autoplay compliance; clicks and tone generation work without clipping.
- Refresh rate detection: Accurate statistical estimation over 60-120 frames without hanging the UI.
- Input lag simulation: Smooth circular target tracking even when artificial delay buffer is filled.
- Production build: `npm.cmd run build` completes with 0 errors and dist/ serves cleanly.
